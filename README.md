# Allsup Timeline V2

A fresh Medicare lead nurture application focused on long-lead-time education, milestone communications, consumer self-service, advisor handoff, product-interest capture, and consent-aware outreach.

## Pilot features
- Premium consumer Medicare timeline
- Separate admin console
- CSV lead import
- Eligibility-date nurture engine
- Education/service vs optional-marketing consent separation
- Hospital indemnity and other product-interest capture
- Advisor follow-up task creation
- Communication log
- Railway deployment support

## Before real-member launch
This deployed build is a staging/pilot. Configure production authentication, persistent database storage, outbound email, verified Twilio messaging, audit logging, role-based admin access, and compliance-approved Medicare/SMS/privacy copy before importing real member data.
